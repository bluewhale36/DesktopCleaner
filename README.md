# 🧹 Desktop Cleaner (Personalized File Organization Automation System)

> **C언어 기반의 개인화 파일 정리 자동화 시스템**
> 
> 사용자의 개입을 최소화하고, 확장자 기반의 규칙을 통해 무질서한 파일들을 빠르고 안전하게 정리합니다.

## 📖 프로젝트 개요

PC 사용 시간이 증가함에 따라 바탕화면과 다운로드 폴더에 다양한 형식의 파일이 무질서하게 축적되는 문제가 발생합니다. 사용자가 일일이 파일을 확인하고 이동시키는 단순 반복 작업은 비효율적입니다.

**Desktop Cleaner**는 이러한 문제를 해결하기 위해 개발되었습니다. C언어의 파일 시스템 제어 기능을 활용하여 파일을 자동으로 분류하고, 사용자가 정의한 규칙에 따라 폴더를 동적으로 생성하여 정리합니다. 특히, 단순 이동이 아닌 '복사 → 무결성 확인 → 원본 삭제'의 프로세스를 적용하여 데이터 손실을 방지합니다.

## 🚀 주요 기능

* **📂 확장자 기반 자동 분류**: 파일의 확장자를 분석하여 미리 정의된 폴더(Images, Documents 등)로 자동 분류합니다.
* **⚙️ 사용자 맞춤 설정**: 
    * 기본 규칙 외에 사용자가 직접 새로운 확장자와 폴더 규칙을 추가하거나 수정할 수 있습니다.
    * 설정 내용은 `rules.cfg` 파일에 자동 저장되어 영구적으로 유지됩니다.
* **🛡️ 데이터 무결성 보장**:
    * 파일 이동 시 데이터 손실을 방지하기 위해 `복사(Copy)` -> `검증(Verify)` -> `원본 삭제(Delete)` 의 '안전한 이동' 프로세스를 준수합니다.
    * 바이너리 모드(`rb`, `wb`) 버퍼링을 통해 안정적인 파일 복사를 지원합니다.
* **📁 동적 디렉토리 생성**: 정리할 목적지 폴더나 하위 카테고리 폴더가 없으면 자동으로 생성합니다(Dynamic Make Directory).

## 🛠️ 기술 스택

* **Language**: C
* **Environment**: Windows 10 / 11
* **Compiler**: MSVC (Visual Studio)
* **Key Libraries**: `<io.h>`, `<direct.h>` (Windows API 활용)

## 📥 설치 및 실행 방법

### 전제 조건
이 프로젝트는 **Windows 환경**에서 실행되도록 설계되었습니다.

### 빌드
1. 프로젝트를 클론합니다.
   ```bash
   git clone https://github.com/bluewhale36/DesktopCleaner.git

   ```

2. Visual Studio에서 솔루션을 열거나 `main.c`를 프로젝트에 추가합니다.
3. 컴파일러 설정에서 `_CRT_SECURE_NO_WARNINGS` 전처리기 정의를 추가하거나 소스 코드 최상단의 정의를 유지합니다.
4. 빌드 후 실행 파일(.exe)을 생성합니다.

### 사용법

프로그램을 실행하면 다음과 같은 메뉴가 나타납니다.

```text
============================================
 Desktop Cleaner v5.0 (Auto-Save)
============================================
 1. 정리 시작하기
 2. 설정 (파일 저장됨)
 3. 종료
============================================

```

1. **정리 시작하기**:
   * 정리할 **원본 폴더 경로**를 입력합니다. (예: `C:\Users\user\Downloads`)
   * 파일이 이동될 **목적지 폴더 경로**를 입력합니다. (엔터 입력 시 원본 폴더 내에 정리됩니다.)


2. **설정**:
   * 새로운 확장자 규칙을 추가하거나 기존 규칙의 폴더명을 변경할 수 있습니다.
   * 예: `.pptx` 파일을 `Presentation` 폴더로 이동하도록 설정.



## 🔍 시스템 구조 및 핵심 로직

### 1. 안전한 파일 이동 프로세스

데이터 안전성을 최우선으로 하여, 단순 `move`가 아닌 직접 구현한 복사 함수를 사용합니다.


### 2. 동적 디렉토리 생성

경로 상에 존재하지 않는 폴더가 있을 경우, 상위 폴더부터 하위 폴더까지 순차적으로 생성하여 오류를 방지합니다.

### 3. 설정 관리

`rules.cfg` 파일을 통해 프로그램이 종료되어도 사용자의 규칙 설정이 유지됩니다.

* **Format**: `[확장자] [폴더명]`
  ```cfg
  jpg Images
  txt Texts
  pdf Documents
  
  ```
